# ISM 3232 Module 10: OOP for Agents

## MatchDay - SSA Soccer Assistant

MatchDay is a mock soccer assistant I created to answer common questions about SSA soccer events. It uses a SoccerSchedule class to provide information about pickup soccer, tournament dates, and locations. The assistant also keeps track of conversation history and directs users to an SSA organizer when they request a team change. This project uses mock information rather than live event data, so the dates and schedules may not always be accurate. One risk is that users could rely on outdated information, which is why important details should be confirmed with an SSA organizer.

## How to Run

Run the assistant using:

python3 my_main.py

## How to Test

Run all tests using:

pytest -v
